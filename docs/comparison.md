# 与其他记忆方案的对比

| 方案 | 记忆方式 | 主动检索 | 专注度 | 依赖 |
|---|---|---|---|---|
| museforge | episodic + semantic | 四信号打分 top-k + 预算 | 有 | 零 |
| 全量历史注入 | 原始对话 | 无（全塞） | 无 | - |
| 向量库（如 faiss） | 向量 | 余弦相似度 | 无 | 重 |
| MemGPT | 分层 + 分页 | 有 | 无 | 重 |

museforge 的定位：**零依赖、可复现、可回归**的参考实现，重点是讲清机制与打分/训练信号，
生产可替换 `Encoder` 与后端。

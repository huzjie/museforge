# 设计笔记

## 为什么嵌入用 md5 而不是真模型？

参考实现要「clone 即跑、零依赖、结果可复现」。md5 种子伪随机向量满足这三点；真实系统把
`Encoder.encode` 换成句向量模型即可，接口不变。

## 为什么训练信号单调趋 1？

可回归。skill 抬升 → recall@1 / 完成率单调上升，基准能写成断言（见 `tests/test_bench.py`）。
对称的「对+1 错-1」在低 skill 期会压死 skill，曲线不单调、不可回归。

## 为什么专注度是个标量？

为了能做护栏与路由：低专注度任务转人工/换模型。模糊的「有没有坚持」无法量化，也无法
写进回归。
